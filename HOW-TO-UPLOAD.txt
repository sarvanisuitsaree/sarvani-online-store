SARVANI WEBSITE - HOW TO PUT IT ON GITHUB (only GitHub, no other app)

OPTION A - UPLOAD THE FILE
 1. Unzip this zip on your computer (GitHub cannot open zip files). You get index.html.
 2. Open your GitHub repository. Delete old files if any (api.php, data, uploads, config.js,
    .htaccess). Keep the CNAME file: it holds your domain name.
 3. Click "Add file" > "Upload files", drop ONLY index.html in, click "Commit changes".

OPTION B - COPY AND PASTE
 1. Open index.html in Notepad (right-click > Open with > Notepad). Select all (Ctrl+A) and copy (Ctrl+C).
 2. In your GitHub repository: "Add file" > "Create new file". Name it exactly: index.html
 3. Paste (Ctrl+V) and click "Commit changes". (If an old index.html exists, open it, click the pencil
    icon, select all, paste over it, and commit.)

THEN
 4. Settings > Pages: Source "Deploy from a branch", Branch "main", folder "/ (root)". Save.
 5. Wait 1-2 minutes and open your domain. If you still see the old page, refresh with Ctrl+Shift+R.

ADMIN
  Click "Admin" on the website and sign in. In the dashboard:
  - "+ Add New Product": name, category, price, sizes, photos, description.
  - "+ Add new category": make categories like Lehengas or Dupattas.
  - After any change click "Publish", download the new index.html, and upload it to GitHub
    the same way. Changes go live only after that upload (GitHub can take up to 10 minutes to show it).

KEEP THE SHOP FAST ON PHONES
  Keep the website file under about 8 MB (roughly 40 products with 2 photos each). The dashboard shows
  the file size and warns you when it gets heavy. GitHub itself stops uploads above 25 MB.
