Admin Setup

One-time setup. It connects the admin to your website's GitHub so products go live automatically. Afterwards, anyone with the ID and password can sign in from any device.

How to get the GitHub access token (2 minutes)
  1. Sign in to GitHub, then open github.com/settings/personal-access-tokens/new
  2. Token name: Sarvani website. Expiration: choose the longest one offered.
  3. Repository access: Only select repositories → pick your website repository.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it (starts with github_pat_) and paste it below.

After this one-time setup, you (or your client) sign in from any phone or computer with just this ID and password. Use a strong password of at least 10 characters.
