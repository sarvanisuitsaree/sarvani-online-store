SARVANI WEBSITE - SETUP (GitHub only)

1. In your GitHub repository, upload ONLY index.html (Add file > Upload files > Commit). Keep the CNAME file.
   Settings > Pages: Deploy from a branch, branch main, folder / (root).

2. Open your website > click "Admin". First time on a device:
   - Create a GitHub token: https://github.com/settings/personal-access-tokens/new
     Repository access: only your website repo. Permissions: Contents = Read and write. Copy the token.
   - Paste repository (yourname/yourshop), the token, and choose your own Admin ID + password.

3. Add products, categories, edit settings. Every change saves directly to GitHub and goes live in 1-2 minutes.
   No downloading or re-uploading files.

FORGOT ID / PASSWORD: Admin > "Forgot ID or password?" > set up again with the token
(make a new token on GitHub if you lost it). Products are never lost.
Change ID/password anytime: Dashboard > ID & Password.
