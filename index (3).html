Automatic publishing (optional, one time)

How to get the GitHub access token (2 minutes)
  1. Sign in to GitHub, then open github.com/settings/personal-access-tokens/new
  2. Token name: Sarvani website. Expiration: choose the longest one offered.
  3. Repository access: Only select repositories → pick your website repository.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it (starts with github_pat_) and paste it below.

Publish to your website

Want one-click publishing? Turn it on once in ID & Password → Automatic publishing. Otherwise:

  1. Download your updated website file with the button below. It is named index.html.
  2. Open your GitHub repository, choose Add file → Upload files, drop index.html in, and click Commit changes.
  3. Wait 1 to 2 minutes, then refresh your website. Your changes are live.

If your browser names the file “index (1).html”, rename it to index.html before uploading, so it replaces the old one.
