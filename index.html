GitHub connection

First-time setup: link your GitHub

This is done once for the whole website (by the website developer). After this, the owner logs in with just ID and password, on any phone or computer. The token is stored locked with the admin password.

Create the token at github.com/settings/personal-access-tokens/new : choose only this repository, and under Permissions set Contents to Read and write.

Reset admin ID & password

Forgot your login? Prove you own the website with your GitHub token, then choose a new ID and password.

Lost the token too? Create a new one on GitHub (same steps), it works just as well.
