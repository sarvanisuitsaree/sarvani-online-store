# Sarvani Suit & Saree – website

Just files – no server, no database. Works on GitHub Pages.

## Put it online (one time)
1. On github.com create a **new repository** (Public).
2. Click **Add file → Upload files** and drag in **everything in this folder**: `index.html`, `data.json`, the `images` folder and `.nojekyll`. Click **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After 1–2 minutes your site is live at `https://<your-username>.github.io/<repository-name>/`.

## Adding or changing products
1. Log in → Dashboard → add / edit products, photos, prices, shop details.
2. Your changes are saved in your browser first (only you can see them – a bar at the top says so).
3. Click **Publish to website** → **Download update file** → unzip it.
4. On GitHub open your repository → **Add file → Upload files** → drag in `data.json` and the `images` folder from the unzipped folder → **Commit changes**.
5. After 1–2 minutes the changes are live for every visitor.

Tip: use the same browser and computer for editing until you have published. If you change the ID/password, publish it too, otherwise the old one stays active on the live site.
